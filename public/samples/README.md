# Sample artifacts

Synthetic, non-compliant mock screens for testing RegSpine and for demos. These are
**fictional** — "ZenTrade" is not a real intermediary and no real product is depicted.
Each one has known violations planted so you can check that the auditor finds them.

## `broker-account-activation.png` / `.pdf`

The same screen in both forms — the PDF exercises the Claude-only PDF path.

A broker segment-activation screen. Planted violations:

- assured-return claim ("Assured 18% p.a.") and an unsubstantiated track record
- false-urgency countdown on a non-expiring offer
- F&O and MTF segments pre-enabled, with **no** mandated F&O risk disclosure anywhere
- two paid add-on services pre-ticked, one auto-renewing
- nomination opt-out as a confirm-shaming grey text link against a filled "Add nominee" button
- all four mandated account-opening documents bundled behind one "I agree"
- charges shown as "other statutory charges as applicable" — no all-in cost
- no SEBI registration number; no GRO / SCORES / ODR route
